# 超清手抄报/主题画快速生成

这是"超清手抄报/主题画快速生成"开发测试版的私有源码仓库。

## 文件说明

- `index.html`：前端单文件页面，需部署到网站公开目录。
- `src/`：按功能拆分的可维护 JavaScript 源码（构建后合并进 `index.html`）。
- `scripts/build.mjs`：把 `src/` 中的模块重新合并到单文件 `index.html`。
- `server/`：异步图片任务后台（Node.js 14 兼容），负责拼接固定提示词并转发上游生图。
- [异步后台服务部署说明.md](./异步后台服务部署说明.md)：服务端异步图片任务后台的部署说明，供后端/运维部署时参考。

## 架构说明

固定风格提示词已经迁移到服务端（`server/server.mjs`），前端只提交用户选项和主题，不再包含任何提示词。因此：

- 单独双击 `index.html` 只能查看界面，**无法生图**。
- 正式生图必须部署异步后台（见部署说明）。
- `server/`、`src/`、`scripts/` 目录禁止公网访问（详见部署说明的 Nginx 配置）。

## 修改和构建

需要 Node.js 18 或更高版本，不需要安装第三方依赖。

```bash
node scripts/build.mjs
```

修改功能时，应优先修改 `src/` 中对应的模块，然后运行上面的构建命令更新 `index.html`。

## 部署

前端与后端必须分目录部署：

- 前端 `index.html` 放在网站公开目录（如 `/var/www/chaoqing-public/`）。
- 后端 `server/` 放在非公开目录（如 `/opt/chaoqing-server/`）。

完整部署步骤、Nginx 反向代理和防御配置见 [异步后台服务部署说明.md](./异步后台服务部署说明.md)。

## 安全说明

- 仓库不保存客户密钥、生成记录、生成图片或本机缓存。
- 固定提示词保存在服务端 `server/server.mjs`，不下发到前端。
- `server/`、`src/`、`scripts/` 目录必须在 Nginx 层屏蔽，禁止公网访问，否则提示词会泄露。

首页 HTML 的缓存配置见 `ops/nginx-frontend-cache.conf`，由部署人员合并至 Nginx；更新页面无需清除网站数据或图库。详见部署说明末尾的缓存处理步骤。


## 发布新版本与更新提醒

每次修改后执行 `node scripts/build.mjs`，会同时生成带版本标识的 `index.html` 和 `server/frontend-version.json`。内容未改变时版本号保持一致。发布时必须使用同一次构建的这两个文件，先更新公开目录的 `index.html`，再更新后端目录的 `frontend-version.json`，并按前文设置首页禁止缓存。

页面每 24 小时最多检查一次，检查时间会保存在浏览器中；重新打开或返回页面也遵守该间隔。到期时检查 `/api/image-tasks/version`。发现不同版本后显示“发现新版本”，用户可选择“刷新更新”或“稍后”（同一版本一天内不再提醒）。任务处理中禁止刷新，更新前保存主题参数；刷新不清除本地图库和设置。服务器版本接口读取最新版本文件，无需为仅更新前端版本文件重启 Node 服务；首次添加该接口或修改后端代码时仍需重启后台。

已在缓存中的旧版页面没有版本检测代码，首次启用时仍需通过强制刷新或带新查询参数的链接加载一次。后续更新才会自动提示。CDN 必须尊重版本接口与首页的禁止缓存响应头。

JPG 格式处理：优先请求上游直接返回 JPEG（质量 95）。若选择 JPG 但上游返回 PNG 等格式，浏览器会按原尺寸、白色底和 0.95 编码质量转换为真实 JPEG 后保存与下载；上游已返回 JPEG 时不二次压缩。转换失败保留原图并明确提醒，不创建新的生图请求。该处理也适用于刷新后恢复的任务，旧的图库图片不会被自动批量转换。

生成引擎通过“设置”按钮后的“生成引擎”按钮打开独立弹窗，选择后自动保存；引擎说明位于弹窗选项下方：线路一为 `gpt-image-2`，线路二为 `gpt-image-2-svip`（0.3 元/张），线路三保留 `gpt-image-2-official`（0.8 元/张）。线路一仍为 0.3 元/张且为默认选项。管理员的三模型选择与图片修改专用模型保持原有规则。
